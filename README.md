Namma Pustaka 📚

A modern Android application for managing library books and student records using Jetpack Compose, Room Database, and Google ML Kit for QR/Barcode scanning.

✨ Features
📖 Book Management
Browse, add, and view detailed information about books in the library.
📷 QR/Barcode Scanner
Easily process book transactions by scanning QR codes or barcodes using CameraX and Google ML Kit.
👨‍🎓 Student Records
Maintain student details and track borrowing history.
🕒 Transaction History
View a complete history of scanned and assigned books.
🏆 Leaderboard
Rank students based on reading or borrowing activity.
🎨 Modern UI
Built entirely with Jetpack Compose following Material Design 3 guidelines.
